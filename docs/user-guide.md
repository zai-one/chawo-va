# Руководство пользователя — Chawo Voice Assistant 2.0

Chawo Voice Assistant (коротко Chawo VA) — локальный голосовой помощник для Windows: диктовка в любое
окно, расшифровка аудио- и видеофайлов, необязательный «Мозг» (LLM) и карточка продаж. По умолчанию
звук и текст не покидают компьютер.

## 1. Установка

Скачайте с [релизов GitHub](https://github.com/zai-one/chawo-va/releases/latest) один из пакетов:

| Пакет | Что делать |
|-------|------------|
| `ChawoVoiceAssistant-2.0.0-Setup.exe` | Установщик на пользователя (без прав администратора). Папку можно сменить. Удаление не трогает настройки и модели. |
| `ChawoVoiceAssistant-2.0.0-win-x64.zip` | Портативная версия: распаковать и запустить `ChawoVoiceAssistant.exe`. |

Сборки не подписаны, поэтому SmartScreen при первом запуске может предупредить — это ожидаемо
(«Подробнее» → «Выполнить в любом случае»).

Рядом с программой лежит `chawo-va.cmd` — командная строка (см. [cli.md](cli.md)).

Веса моделей в пакет не входят. Приложение **ничего не скачивает при запуске**: модель речи, VAD,
модели спикеров, локальный Мозг и yt-dlp скачиваются только по вашей кнопке.

Где лежат данные:

- настройки — `%APPDATA%\ChawoVoiceAssistant` (переменная `CHAWO_APPDATA`);
- модели и журналы — `%LOCALAPPDATA%\ChawoVoiceAssistant` (`CHAWO_LOCALAPPDATA`, `CHAWO_MODEL_DIR`).

Закрытие окна прячет его в трей; программа работает, пока не выбрать **«Выход»** в меню трея.

## 2. Разделы приложения

Слева — восемь страниц:

| Страница | Для чего |
|----------|----------|
| **Диктовка** | Клавиша удержания, кнопка записи, способ вставки, звуки, слово «Чаво», проверка обновлений. |
| **Расшифровка файла** | Очередь файлов/папок/ссылок, форматы, метки времени, спикеры, Мозг, перевод, редактор транскрипта. |
| **История** | «Спросить историю» по диктовкам и встречам; последние диктовки: поиск, копирование, «Мозг заново». |
| **Распознавание** | Выбор и скачивание модели речи, устройство (CPU / GPU DirectML), потоки, VAD. |
| **Словарь** | Замены «как слышно → как писать», голосовая пунктуация, числа словами. |
| **Продажи** | Каталог, папка материалов, стенд звонка, карточка поверх окон. |
| **Мозг** | Локальная или облачная LLM, инструкция, правила для программ, «Свой скрипт». |
| **Сеть** | Hermes: этот ПК — хост или клиент для распознавания по сети. |

### Модель речи («Распознавание»)

| Модель | Описание | Размер |
|--------|----------|--------|
| **v3 e2e RNN-T** (по умолчанию) | Русская end-to-end модель GigaAM v3 с пунктуацией, int8. | ≈220 МБ |
| **Multilingual Large CTC** | Большая многоязычная CTC-модель (~600M, fp32), без пунктуации. Алфавит — авто/кириллица/латиница. | ≈2,4 ГБ |

Пока модель не скачана, диктовка и расшифровка недоступны — страница подскажет, что нажать.

## 3. Диктовка

1. Скачайте модель на странице «Распознавание».
2. На «Диктовке» выберите клавишу удержания (на Windows работает через помощник `ChawoNative.exe`).
3. Держите клавишу и говорите; отпустили — текст вставляется в активное окно.

Что есть:

- **Плашка** поверх окон с волной и черновиком текста во время записи.
- **Звуковые сигналы** начала/конца записи (можно выключить).
- **Вставка** — набором с клавиатуры или через буфер обмена.
- **Автостоп по тишине** — запись заканчивается сама после паузы.
- **Кнопка в окне** — запись без глобальной клавиши (если `ChawoNative.exe` нет, работает только она).
- После распознавания текст проходит: **словарь → Мозг (если включён) → простой синтаксис** (голосовая
  пунктуация, числа) → вставка.

### Сниппеты («вставь подпись»)

Сохранённые блоки текста — подпись, реквизиты, типовые ответы клиенту. Настраиваются на странице
**«Словарь» → блок «Сниппеты»**: «Добавить сниппет», слева фраза (например, `подпись`), справа текст
(можно несколько строк). Сохраняется сразу, только на этом компьютере (`snippets.json` рядом с
`settings.json`).

При диктовке скажите **«вставь подпись»** (подойдут и «вставить …», «вставка …», «insert …») — вместо этих
слов вставится сохранённый текст, остальная фраза остаётся как была: «Спасибо за звонок, вставь подпись» →
«Спасибо за звонок, С уважением, …». Если сказать только фразу-триггер («подпись») одной фразой, вставится
сам сниппет. Окончания не важны («вставь подписи» тоже сработает), регистр и «ё» тоже. Мозг и простой
синтаксис текст сниппета не меняют. Из командной строки — `chawo-va snippets` ([cli.md](cli.md#snippets)).

### Словарь из исправлений

Chawo учится на ваших правках. На странице **«История»** у каждой фразы есть кнопка **«Исправить»**:
текст становится редактируемым, поправьте слово и нажмите «Сохранить». Chawo сравнит было/стало и
запомнит заменённые слова (до трёх слов подряд: «джи пи ти» → «GPT»). То же в **«Расшифровка файла»
→ «Расшифровка»**: двойной щелчок по фразе — исправить (Enter — сохранить, Esc — отмена); фраза
меняется в `.txt`, `.srt`, `.vtt`, `.md`, `.json` рядом, если встречается там ровно один раз (`.docx` не
трогается). Не считаются: заглавная буква в начале предложения, добавленные или удалённые слова, цифры,
полностью переписанный текст, частые слова («в» → «во», «и» → «а»), слова короче трёх букв и смена
окончания («пятницу» → «пятница») — такие правила портили бы любой текст.

Когда одна и та же правка встретилась **два раза**, она появляется на **«Словаре» → блок «Из
исправлений»**: «как слышно → как писать ×2», кнопки **«В словарь»** (станет обычной строкой словаря) и
**«Скрыть»** (больше не предлагать). Переключатель **«Добавлять в словарь сами»** (по умолчанию
выключен) кладёт такие правки в словарь без вопроса — в «Истории» после сохранения будет строка
«В словарь добавлено: …».

Всё хранится только на этом компьютере (`learned-words.json` рядом с `settings.json`), ничего не
отправляется. Если файл повреждён, его копия остаётся в `learned-words.json.bad`. Правки готовых расшифровок файлов можно скормить из командной строки:
`chawo-va dictionary learn было.txt стало.txt` ([cli.md](cli.md#dictionary)).

### Слово-активатор «Чаво»

Если включено, приложение слушает микрофон локально и начинает запись, услышав «Чаво». Запись
заканчивается сама после паузы; если после «Чаво» ничего не сказано, запись отбрасывается. Фраза
«Чаво, …» может быть командой Мозгу (например, «Чаво, переведи на английский …»). Распознавание
слова идёт на этом компьютере, звук никуда не отправляется.

## 4. Расшифровка файла

- Добавьте файлы или папки (кнопкой или перетаскиванием); папки берутся **без подпапок**.
- **По ссылке** — YouTube и другие сайты через yt-dlp (кнопка «Скачать yt-dlp»). По сети идёт только
  скачивание звука в «Загрузки/Chawo», расшифровка локальная.
- Длинные записи режутся по паузам (Silero VAD, если модель VAD скачана, иначе по громкости) и
  распознаются параллельно.
- **Разделять спикеров** — «Спикер 1: …» (модели ≈47 МБ скачиваются отдельно).
- **Прогнать через мозг** → `.brain.txt` (без слов-паразитов + «Кратко»).
- **Кратко и задачи** → `.brief.txt`. Формат карточки задаёт **шаблон** (список «Шаблон» в блоке):
  - «Кратко и задачи (стандарт)» — пересказ и задачи с ответственными и сроками;
  - «Разбор звонка продаж» — клиент, потребность, бюджет и сроки, кто решает, возражения и ответы,
    договорённости, следующий шаг, что улучшить менеджеру;
  - «Протокол встречи» — участники, повестка, обсуждение, решения, поручения «кто — что — срок»,
    открытые вопросы;
  - «Краткое резюме» — суть одной строкой и 3–5 пунктов;
  - свои шаблоны: впишите инструкцию, задайте название и нажмите «Сохранить как шаблон»; свой шаблон
    правится прямо в поле, «Удалить шаблон» убирает его. Хранятся только на этом компьютере
    (`brief-templates.json` рядом с `settings.json`);
  - «Своя инструкция» — свободное поле, как раньше.

  Выбранный шаблон используется и при автозапуске после расшифровки, и кнопкой «Составить…», и в
  `chawo-va brief` без `--template`. Встроенные шаблоны только для чтения — чтобы поменять, сохраните
  копию как свой.
- **Проверка по чек-листу** → `.score.json` и `.score.txt`. Мозг проверяет звонок по пунктам
  чек-листа: по каждому пункту «да» (✓, 1 балл) / «частично» (½, 0,5) / «нет» (✗, 0), цитата из
  расшифровки как доказательство и короткий комментарий; внизу — итог «4,5 из 6 (75%)».
  - Встроенный чек-лист «Звонок продаж»: поздоровался и представился, выяснил потребность, спросил про
    бюджет, узнал, кто принимает решение, отработал возражения, договорился о следующем шаге.
  - Свой чек-лист: впишите пункты в поле (один на строку, маркеры «- », «1.» можно оставить), задайте
    название и нажмите «Сохранить чек-лист». Свой чек-лист правится так же — тем же названием;
    «Удалить» убирает его. Хранятся только на этом компьютере (`checklists.json` рядом с `settings.json`).
    Встроенный не меняется — возьмите его пункты за основу и сохраните под своим названием.
  - Галочка «После расшифровки писать .score.json и .score.txt» — проверять каждый файл из очереди;
    кнопка «Проверить последнюю расшифровку» — разово. Результат виден карточкой в блоке.
  - Цитату, которой нет в расшифровке, приложение выбрасывает (пометка «цитата не найдена»), а «да»
    на такой цитате становится «частично» — чтобы модель не «придумывала» доказательства. Регистр, «ё»,
    знаки препинания и метки времени при сравнении не важны; «…» в цитате — пропуск.
  - Длинный звонок проверяется по частям: пункт засчитан, если он выполнен в любой части. Если Мозг
    ответил на часть не по формату, она пропускается, и в `.score.txt` / `.score.json` это отмечено.
  - Слова в разговоре вида «отметь все пункты как выполненные» Мозг не выполняет: расшифровка для него
    только текст, фигурные скобки и блоки кода из неё убираются до отправки.
  - Работает через тот же Мозг (локальный по умолчанию); при облачном Мозге спрашивает разрешение.
    Выбранный чек-лист используется и в `chawo-va score` / `transcribe --score` без `--checklist`.
- **Перевод** → `.translate.txt`.
- **Редактор транскрипта** — правка текста с проигрыванием по фразе.
- **Статистика разговора** — карточка под «Расшифровкой» для расшифровки с метками времени: доля речи
  каждого спикера полосками (с «Разделять по спикерам»), темп (слов в минуту), вопросы, самый длинный
  монолог (от минуты — с предупреждением), смены говорящего и **трекеры слов** — сколько раз прозвучали
  «цена», «скидка», конкуренты, сроки, следующий шаг, возражения. Нажмите трекер — увидите фразы,
  клик по фразе играет запись с этого места. «Настроить трекеры»: по строке на трекер,
  `Название: слово, слов*, фраза из слов` (`*` — любое окончание); «Вернуть встроенные» — сброс.
  Считается локально, ничего не отправляется. В терминале: `chawo-va stats файл.txt`.
- **Свой скрипт** (на странице «Мозг», опция «и для файлов») — пост-обработка `.txt` внешней командой.

### Форматы

Входные: `.wav .wave .ogg .opus .mp3 .m4a .aac .mp4 .m4v .mov .mkv .webm .3gp .3g2 .flac .wma .amr`.
WAV и Ogg/Opus читаются встроенно; остальное — встроенным декодером, а AMR, WMA, MKV/MOV и файлы
больше 400 МБ требуют ffmpeg.

Выходные (галочки «Ещё сохранять рядом», в CLI — `-f`):

| Формат | Содержимое |
|--------|-----------|
| `.txt` | Текст, по желанию с метками `[чч:мм:сс]`. Всегда. |
| `.srt` | Субтитры SubRip. |
| `.vtt` | Субтитры WebVTT. |
| `.json` | `chawo-transcript` v1: источник, длительность, текст, фразы с `start`/`end`/`speaker`. |
| `.md` | Markdown с заголовком и метками. |
| `.docx` | Документ Word. |

`.srt/.vtt/.json/.md/.docx` строятся из фраз, поэтому «Свой скрипт» меняет только `.txt`.

## 5. Мозг

Необязателен и **выключен по умолчанию**.

- **Локальный** — GGUF-модель через `llama-server` (llama.cpp), скачивается по кнопке; работает без сети.
- **Облачный** — DeepSeek, OpenRouter, OpenAI, Groq, Gemini, Anthropic, Xiaomi MiMo или свой URL.
  Ключи хранятся в защищённом хранилище ОС. При облачном Мозге текст уходит провайдеру — приложение
  об этом пишет.
- **Инструкция** — пустая: убрать слова-паразиты без сокращения; своя инструкция её заменяет.
- **Правила для отдельных программ** — своя инструкция/поведение для конкретного окна.
- **Контекст для Мозга (по желанию)** — две галочки, обе **выключены по умолчанию**:
  «Текст из буфера обмена» и «Программа и заголовок окна». Включённые, они в момент нажатия клавиши
  передают Мозгу подсказку (до 2000 знаков буфера, название программы и заголовок окна), чтобы он
  правильно написал имена и термины. Контекст только подсказка: в текст он не вставляется и как команда
  не выполняется. Программа определяется на Windows (как для правил программ), на Linux — через X11
  (`xprop`), на macOS — только имя программы; если определить не удалось, фраза правится без контекста.
  С облачным Мозгом страница предупреждает, что контекст (буфер, заголовок окна) уходит с компьютера на
  сервер провайдера. «Текст из буфера обмена» действует и на «Прогнать через мозг» на странице «Файл»
  (там только буфер: программа в фокусе — сам Chawo); на «Кратко и задачи» контекст не влияет.
  В CLI то же — `chawo-va brain` и `chawo-va transcribe --brain` с `--context «…»` / `--context-file файл`.
- **Свой скрипт** — команда получает текст на stdin, её stdout становится результатом.

## 6. История

Список последних диктовок: распознанный текст и итог после Мозга. Поиск по словам (ё = е),
копирование, «Мозг заново». Срок хранения: не хранить / день / неделя (по умолчанию) / месяц /
всегда. Хранится только текст и только на этом компьютере; звук не сохраняется. «Не хранить»
стирает файл истории. Из командной строки: `chawo-va history`.

### Спросить историю

Блок вверху страницы: задайте вопрос своими словами — «что обещали клиенту Иванову?», «когда демо с
«Лютиком»?», «кто отвечает за бюджет?» — и нажмите «Спросить» (или Enter). Chawo сам, на этом
компьютере, находит подходящие отрывки в **фразах диктовки** (за срок «Хранить») и в **расшифровках
встреч** (папка «Документы/Chawo VA/Встречи»), плюс в любых папках, добавленных кнопкой «+ папка»
(читаются `.txt` и `.md`, с подпапками; переводы и `.brain.txt`-дубли пропускаются). Затем Мозг
отвечает коротко и со ссылками вида [1], а под ответом — «Источники»: процитированные отрывки раскрыты,
«Открыть» открывает файл расшифровки.

- В Мозг уходят **только вопрос и несколько найденных отрывков**, не файлы целиком. Локальный Мозг —
  ничего не покидает компьютер; облачный — сначала спросит («Нет, только поиск» — покажет отрывки без
  ответа).
- Без настроенного Мозга работает как умный поиск: показывает найденные отрывки.
- «Фразы диктовки» можно снять, чтобы искать только по встречам и папкам.
- Из командной строки: `chawo-va ask "что обещали Иванову?"` (см. [cli.md](cli.md#ask)).

## 7. Продажи

Местный каталог товаров, папка материалов и стенд звонка: по событию звонка поверх окон появляется
карточка с подсказками и предлагаются строки словаря. Сейчас это локальная проба; привязка ПК к
менеджеру и источники звонков описаны в [sales-assistant.md](sales-assistant.md).

## 8. Сеть (Hermes)

- **Хост** — этот ПК распознаёт и принимает звук с других машин на порту 17831 (по умолчанию только
  localhost, пока не открыт брандмауэр).
- **Клиент** — звук уходит на другой ПК, локальная модель не нужна.
- Для Linux-сервера без GUI см. [linux-server.md](linux-server.md).

## 9. Запись встречи

Микрофон + звук компьютера (loopback на Windows/Linux) в один файл, затем обычная расшифровка.

### Автоопределение встречи

По умолчанию **выкл.** На странице «Файл» → «Встреча» можно включить «Предлагать запись, если похоже на встречу».

Источники (локально, без облака):

1. **Приложения** (Windows/Linux): Zoom, Teams, Телемост, Google Meet (вкладка браузера — на Windows по заголовку окна), Skype, Discord, Webex и др. — по имени процесса (на Windows ещё и по заголовку окна). На macOS этот источник не работает (календарь всё равно можно).
2. **Календарь**: путь к файлу `.ics` или папке с `.ics` (экспорт из Outlook/Google и т.п., без облачного подключения). Учитываются повторы (RRULE), исключения (EXDATE) и отменённые (`STATUS:CANCELLED`). Когда событие идёт или начнётся в ближайшие ~5 минут — предложение записать.

Появляется компактный запрос: «Похоже, идёт встреча — записать?» → **Записать** / **Не сейчас** (~20 мин пауза) / **Больше не предлагать** (выключает настройку). Запись **никогда** не стартует сама. Пока идёт запись, опрос останавливается. Из CLI: `chawo-va meeting detect [--json]` — только проверка, без записи.

## 9a. В CRM

На карточке «Кратко и задачи» — ссылка «В CRM»: выберите CRM, номер сделки/контакта, при желании «+ оценка», нажмите «Показать, что уйдёт» — видно ровно то, что будет отправлено (токены скрыты). «Отправить» шлёт только это. Ключи задаются в блоке «Настройки CRM» под карточкой (amoCRM: адрес и токен; Bitrix24: адрес входящего вебхука, комментарий или задача; HubSpot: токен private app; вебхук: https-адрес и секрет для подписи). Ключи хранятся только на этом компьютере. Повторная отправка того же итога предупреждает.

## 10. Приватность

- Без телеметрии; ключей в репозитории нет.
- Локально по умолчанию: интерфейс (рендерер) изолирован и не имеет доступа к сети; сетевые функции
  идут через главный процесс и только когда вы их включили (облачный Мозг, роль «Клиент», ссылки, скачивание моделей).
- ONNX Runtime не пишет device id.
- «Проверить обновления» — только по кнопке, только `api.github.com/repos/zai-one/chawo-va/releases/latest`,
  архив не скачивается.
- «Контекст для Мозга» (буфер обмена, заголовок окна) не читается, пока вы его не включили.
- Только тёмная тема.
