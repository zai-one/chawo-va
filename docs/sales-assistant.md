# Chawo VA — контракт sales-ассистента

Поведение и формы данных, общие для локальной пробы в этом приложении и для будущего SaaS на другом стеке. Здесь нет URL, авторизации и описания бэкенда — только что видит менеджер и какие сущности для этого нужны.

## Сценарий

1. Звонок привязан к менеджеру и (позже) к трубке.
2. На компьютере этого менеджера всплывает карточка поверх окон.
3. Карточка помогает в разговоре: скрипт / короткая строка каталога, точная позиция или ближайший аналог, фрагмент из материалов.
4. Словарь подсказок строится из тех же материалов и **не применяется сам** — человек добавляет строку.

Сейчас всё это крутится локально на одном ПК. Позже те же формы отдаёт облако на ПК менеджера при звонке на его трубку.

## Режимы

| Режим | Что делает |
| --- | --- |
| Диктовка | Обычный push-to-talk: речь → текст в поле. Карточка продаж скрыта. |
| Продажи | Та же диктовка плюс карточка по живому черновику. Сеть и модель для карточки не обязательны. |

Переключение режима — настройка клиента. Облако позже может включать «продажи» только для роли менеджера.

## Сущности (формы данных)

Независимы от Windows и WPF.

### Строка каталога

- `code` — артикул / код, который ищут в речи
- `name` — название для карточки
- `line` — одна короткая строка (скрипт, цена, пометка)
- `similarCode` — необязательный запасной код; попадание по нему = «похоже», не точное

### Попадание по каталогу

- `kind`: `exact` | `similar`
- `code`, `name`, `line` — что показать
- `exact`: в тексте есть `code` как отдельный токен
- `similar`: есть `similarCode`, либо ближайшее `name` по пересечению букв, если кода нет

### Фрагмент материалов (RAG)

- `text` — короткий абзац / кусок
- `source` — откуда взяли (имя файла сейчас; позже — id документа)

Правило сейчас: фрагмент ищется **только если точного кода нет** (`kind = similar`) и подставляется **под** строкой каталога на той же карточке. Позже тот же фрагмент может прийти с API вместе с попаданием.

### Подсказка словаря

- `heard` — как обычно слышно / пишется по-русски
- `written` — как писать (часто латинский бренд)
- `source` — материал, из которого взяли пару

Подсказки **не пишутся в словарь автоматически**. Пользователь явно добавляет строку. Позже SaaS может предлагать тот же список; применение по-прежнему ручное или отдельным действием клиента.

## Локально сейчас

- Каталог — список строк в настройках приложения.
- Материалы — папка `.txt` / `.md` на диске этого ПК. Никуда не загружается.
- Карточка, словарь, диктовка — один процесс на Windows.

## Позже (SaaS, без деталей API)

Те же формы:

- звонок → менеджер / трубка → событие на его клиенте
- ответ с `catalog hit` + опционально `rag snippet`
- отдельно — список `dictionary suggestion` из тех же материалов организации

Клиент только рисует карточку и предлагает строки словаря. Как устроены хранение, поиск и доставка — вне этого документа.
