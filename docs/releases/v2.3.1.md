## Chawo Voice Assistant 2.3.1

Исправления: клавиша озвучки читает выделение на сайтах, голос не меняется посреди текста,
надиктованное можно сохранять в журнале буфера (Win+V).

### Установка
- **Установщик:** `ChawoVoiceAssistant-2.3.1-Setup.exe` (на пользователя, папку можно сменить)
- **Портативный zip:** `ChawoVoiceAssistant-2.3.1-win-x64.zip`

В обоих пакетах рядом с программой — CLI **`chawo-va.cmd`**. Веса речи и Мозга в архив не входят:
скачиваются при первом использовании. Обновление поверх 2.3 сохраняет настройки, историю и модели.

### Озвучка
- **Клавиша «Озвучить» читает выделение со ссылками, кодом и картинками.** Раньше на странице сайта
  такое выделение давало «Выделите текст, который прочитать»: браузер держит фокус на ссылке внутри
  выделения, и UI Automation отвечала «ничего не выделено». Теперь выделение ищется и у элементов
  вокруг фокуса, а если программа его так не отдаёт, клавиша копирует его Ctrl+C и возвращает прежний
  буфер. В терминалах Ctrl+C не нажимается.
- **Что читается вслух:** картинки пропускаются, ссылка читается своим текстом, адрес — только доменом
  («github.com»), разметка Markdown (звёздочки, решётки, обратные кавычки) не произносится.
- **Один голос на весь текст.** С пустым голосом сервис выбирает его сам, а некоторые (Fish) — заново на
  каждый запрос, поэтому части текста звучали разными голосами. Теперь с пустым голосом текст не
  делится на русский и английский, а у моделей Fish подставляется один постоянный голос. Под полем
  «Голос» — подсказка. При смене модели голос из списка другой модели заменяется подходящим.

### Диктовка
- **Галочка «Сохранять фразу в журнале буфера обмена (Win+V)»** на странице «Диктовка» (выключена по
  умолчанию). С ней надиктованное появляется в Win+V, а прежний буфер возвращается через секунду. В
  облачный буфер на другие устройства фраза не уходит.

### Важно
- Сборка без подписи: SmartScreen может предупредить при первом запуске — «Подробнее → Выполнить в
  любом случае».
