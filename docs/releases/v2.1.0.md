## Chawo Voice Assistant 2.1.0

Обновление основы приложения: всё, что было в 2.0, на месте, работает на современном стеке, данные и
ключи хранятся надёжнее, появилась очистка диска.

### Установка
- **Установщик:** `ChawoVoiceAssistant-2.1.0-Setup.exe` (на пользователя, папку можно сменить)
- **Портативный zip:** `ChawoVoiceAssistant-2.1.0-win-x64.zip`

В обоих пакетах рядом с программой — CLI **`chawo-va.cmd`**. Веса речи и Мозга в архив не входят:
скачиваются при первом использовании. Обновление поверх 2.0 переносит всё само при первом запуске.

### Новое
- **«Место на диске»** на «Распознавании»: «Найти лишнее» показывает, что можно удалить, с размерами —
  папки старой версии GigaPisar со старыми моделями, недокачанные файлы, старые движки Мозга,
  неиспользуемые модели, копии данных, временные файлы, давно расшифрованные записи встреч.
  Безопасное отмечено сразу; выбранная модель и записи без расшифровки не трогаются. То же в CLI:
  `chawo-va cleanup` и `chawo-va cleanup --yes`.
- Старые версии движка Мозга удаляются сами после обновления движка.

### Данные и приватность
- История диктовок и журнал «В CRM» — в базе `chawo.db` (SQLite). «Удалить» и «Не хранить» стирают текст
  и из байтов файла. Прежние `history.jsonl` / `crm-sent.json` переносятся при первом запуске;
  текстовая копия истории после переноса удаляется.
- Ключи облачного Мозга и токены CRM — в **Диспетчере учётных данных Windows**, а не в файлах.
  CLI видит ключи, заданные в приложении. Токены CRM больше не лежат открытым текстом.
- Повреждённый `crm.json` больше не стирает токены.

### Безопасность
- Electron 44 (Node 24) вместо Electron 38, у которого закончилась поддержка.
- Пакет защищён Electron fuses: без `NODE_OPTIONS` и `--inspect`, код только из `app.asar` с проверкой
  целостности. Страницы открываются со своей схемы `chawo-app://`, а не с `file://`.
- Окно общается с системой только по описанным каналам; вызовы не из окна приложения отклоняются.

### Под капотом
- Интерфейс на React 19, сборка Vite 8 + electron-vite, монорепозиторий pnpm, TypeScript 6.
- Проверки: ESLint с проверкой типов, Knip, 1135 юнит-тестов, e2e приложения и CLI, сценарии Playwright,
  проверка собранного пакета в CI.
- Старое WPF-приложение 1.x удалено из репозитория (осталось в истории git).

### Важно
- Сборка без подписи: SmartScreen может предупредить при первом запуске. Подпись включится, когда будет
  сертификат (конфигурация готова).
